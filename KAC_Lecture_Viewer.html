번역 엔진

Free: 비공식 API. 전문용어 오역 잦음, 사용량 제한 있음.
Cloud: 월 50만자 무료. 안정적이고 전문용어 정확도 높음.

🌐 강의 출력 언어

English: 한국어 강의 → 영어 자막 + 영어 음성
Español: 한국어 강의 → 스페인어 자막 + 스페인어 음성
LLM POLISH가 켜져 있으면 선택한 언어의 자연스러운 발표 문장으로 한 번 더 다듬습니다.

💬 교육생 Q&A 입력 언어

교육생 스마트폰 플랫폼에서 마이크나 텍스트로 질문하면, 강사용 Q&A에는 원문 질문과 한국어 번역이 함께 표시됩니다.
학생 플랫폼에서 언어를 선택해 보내면 그 언어가 우선 적용되고, 정보가 없을 때만 이 설정을 사용합니다.

Google Cloud API Key

발급: Google Cloud Console → Cloud Translation API 활성화 → API 키 생성
무료 한도: 월 500,000자 / 초과 시 $20/백만자
키는 이 브라우저에만 저장됩니다.

✨ LLM 발표문 다듬기 (출력 언어 자동)

역할: Google 번역 결과를 다시 한 번 읽고, 국제교육 강사가 말하는 자연스러운 발표용 영어로 다듬습니다.
전문용어: Glossary의 ACARS, VDL Mode 2, CPDLC 같은 표기를 유지하도록 지시합니다.
속도: 먼저 빠른 Google 번역 자막을 띄운 뒤, LLM 결과가 오면 최종 문장으로 교체합니다.
키는 kac_gemini_key.txt에 별도 저장됩니다. kac_settings.json에는 저장하지 않아 공유/백업 시 안전합니다.

⚡ 통역 출력 방식

⚡ 속도 우선: 말이 쭉 이어져 쓰이다 멈추면 한 문장으로 즉시 번역·낭독. LLM 정화본은 도착하면 자막만 조용히 교체 (원본 흐름)
✨ 품질 우선: LLM 정화가 끝날 때까지 기다렸다가 자막·음성을 정화본으로 한 번에 출력 (반 박자 지연)

🤖 음성 어시스턴트 (자비스 / 아리야)

강의 중 "자비스" 또는 "아리야"로 시작해 질문하면 통역되지 않고 — 시간·날짜·날씨는 즉답, 그 외 질문은 AI가 영어 2문장으로 답해 낭독합니다.
웹 검색 ON이면 최신 정보·환율·뉴스 등도 검색해서 답합니다(응답 1~3초 추가).

🎤 음성인식 (STT) 엔진

Web Speech: Chrome 내장. 무료지만 영어 약어(ACARS, CPDLC 등) 인식 어려움.
Cloud STT: Glossary의 영문 용어를 자동 힌트로 전송 → 약어 인식 대폭 향상. 분당 $0.016 (월 60분 무료).
Cloud STT 설정 방법 (클릭)
1. pip install google-cloud-speech 실행
2. GCP 콘솔에서 Speech-to-Text API 활성화
3. 서비스 계정 JSON 다운로드 → 같은 폴더에 kac_service_account.json으로 저장
4. 서버 재시작 → 위 ⭐ 버튼 클릭
자세한 안내: README_GCP_STT.md 참고
